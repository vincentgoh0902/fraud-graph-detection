About this demo

Static, no backend: every number was generated at build time by the same serving code as the project's dashboard, and a test checks they match. Model ….

The full stack, with Neo4j and a FastAPI service, runs locally: Serving. Code, method and results: GitHub repository and README.

Data, licence and attribution

Source: the Elliptic Data Set by Elliptic, licensed CC BY-NC-ND 4.0; this demo is non-commercial. Transaction IDs, time steps and payment edges are unmodified excerpts. Risk scores, flags, communities and SHAP values are this project's model outputs. Not included: transaction features, labels and the full edge list. Per-step metrics are aggregates from the project's logged test results. Data: Hugging Face dataset.

M. Weber et al., “Anti-Money Laundering in Bitcoin: Experimenting with Graph Convolutional Networks for Financial Forensics”, KDD ’19 Workshop on Anomaly Detection in Finance, 2019.
